# Spike D — 무음 m분 자동 종료

**질문:** "말소리가 없는 상태"를 오탐 없이 감지해 자동으로 멈출 수 있는가?

## 이미 된 것

판단 로직은 `app/VoidCore/Sources/VoidCore/SilenceMonitor.swift`에 구현되어 있고 단위 테스트가 붙어 있다.

- 프레임마다 `isSpeech`(VAD 결과)를 받아 연속 무음 시간을 잰다
- 0.5초 미만의 짧은 소리(기침, 문 닫힘)는 무음을 깨지 않는다
- 종료 30초 전에 `warning` 이벤트 → 알림/Live Activity로 "계속 녹음" 버튼 노출 (`extend`)
- m분 도달 시 `timeout`

## 남은 것: VAD 선택

| 후보 | 장점 | 단점 |
|---|---|---|
| 에너지(RMS) 임계값 | 구현 10줄, 의존성 없음 | 에어컨·키보드 소리를 말소리로 오인 → 영원히 안 멈춤 |
| Silero VAD (Core ML 변환본) | 사람 목소리만 판정, 2MB 미만 | 모델 통합 필요 |
| SpeechAnalyzer 결과 유무 | 추가 모델 없음 | 지연이 크고 판정 기준이 불투명 |

**권장:** Silero VAD. 먼저 RMS 버전으로 파이프라인을 붙이고, 아래 오탐 테스트에서 실패하면 교체.

## 오탐 테스트 세트

각 환경에서 5분 녹음 후 `isSpeech` 비율을 측정:

- [ ] 조용한 방 (기대: ~0%)
- [ ] 에어컨/환풍기 소음 (기대: ~0%)
- [ ] 키보드 타이핑 (기대: ~0%)
- [ ] 옆 테이블 웅성거림이 있는 카페 (판단 필요 — 회의가 끝났는데 안 멈추는 쪽이 끊기는 쪽보다 낫다)
- [ ] 실제 회의 중 30초 이상 침묵 구간 (기대: 끊기지 않음)
